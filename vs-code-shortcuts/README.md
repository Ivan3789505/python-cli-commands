| Сочетание клавиш       | Действие                           |
|------------------------|------------------------------------|
| `Shift` + `Alt` + `↑`  | Копировать строку вверх            |
| `Shift` + `Alt` + `↓`  | Копировать строку вниз             |
| `Ctrl` + `Alt` + `↑`   | Мультикурсор вверх                 |
| `Ctrl` + `Alt` + `↓`   | Мультикурсор вниз                  |
| `F2`                   | Переименовать переменную           |
| `Ctrl` + `D` + `D`     | Выделить одинаковый набор символов |
| `Ctrl` + `Z`           | Отменить предыдущее действие       |
| `Ctrl` + `Z` + `Shift` | Отменить предыдущее действие       |
